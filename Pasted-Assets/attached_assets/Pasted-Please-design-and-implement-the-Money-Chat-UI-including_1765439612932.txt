Please design and implement the Money Chat UI, including the empty-state, contact list, invite flows, and simple transaction threads.

Use the existing iMaliChat brand: navy background, white text, pink primary actions, yellow accents.

1. Data models

Create TypeScript types in src/types (or similar):

type Contact = {
  id: string;
  name: string;
  phoneNumber: string;
  isOnImaliChat: boolean;
  lastActiveAt?: string;    // ISO string or undefined
};

type MoneyChatThread = {
  id: string;
  contactId: string;
  lastUpdatedAt: string;
};

type MoneyChatEntry = {
  id: string;
  threadId: string;
  direction: "sent" | "received" | "request_out" | "request_in";
  amount: number;           // in minor units or tokens
  currency: "ZAR" | "TOKENS";
  status: "pending" | "completed" | "declined";
  createdAt: string;
  note?: string;
};


Create a fakeApi/moneyChat.ts module that returns:

A list of contacts (some isOnImaliChat: true, some false).

Some mocked threads and entries for testing “recent chats”.
